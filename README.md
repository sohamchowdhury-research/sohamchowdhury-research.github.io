# Soham Chowdhury — personal website (flat version)

All files sit in one folder (no sub-folders), so they upload to GitHub easily.

- `site.js` — all text: bio, interests, education, news, instruments, exposure & accolades, courses, contact links, CV link.
- `publications.js` — publications (copy a block to add a paper).
- Photos: upload next to `index.html`, then write the file name in `site.js` (e.g. `img: "escaprobe.jpg"` for an instrument).
- `style.css` — colours and fonts (the `:root` blocks at the top and under "THEME v2").
- Do not edit the `.html` files or `app.js`.

Edit on GitHub: open the file → pencil icon → change → Commit changes.
Keep large PDFs in Google Drive and link to them.
